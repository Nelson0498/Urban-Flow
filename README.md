## Sprint 1

### Objetivo
Aplicar los conocimientos adquiridos para el versionado de código, la organización, limpieza del código y la utilización de pandas.

### Contexto
La localidad llamada Vaalserberg de Bélgica se encuentra en la zona fronteriza y limita con los paises como Países Bajos y Alemania. Esta localidad cuenta con un sistema de radares urbanos para la detección de infracciones por exceso de velocidad. Los registros históricos provienen de sistemas heredados, el cuál presenta errores de formato, faltante de datos generando registros inconsistentes en el nuevo sistema. Debemos analizar y depurar los datos del viejo sistema.
